The live website chatbot and project-operated public MCP endpoint are retired. The documentation and server package remain available.

1. [Install and connect the server]({{ '/getting-started/' | relative_url }}) in a local MCP client, or use your own HTTP deployment.
2. Copy a prompt from the [Prompting Guide]({{ '/prompting-guide/' | relative_url }}).
3. Ask your connected client to query FDIC data.

Example:

```text
Find active FDIC-insured banks in North Carolina with more than $1 billion in assets.
```
